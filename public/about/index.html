About Enshrouded Builds

EnshroudedBuilds.org is an independent fan site that publishes build guides for Enshrouded by Keen Games. Our goal is simple: clear, up-to-date Enshrouded builds for every playstyle, rewritten for the 1.0 full release.

Methodology: how we keep guides accurate

Enshrouded 1.0 launched on October 15, 2026 and reset every skill tree, so many guides online still show Early Access numbers. This is how every guide on this site is put together:

  • Official facts first. Release dates, new skills, new spells, the level cap and hotfix changes are taken from Keen Games' official 1.0 posts and the Steam patch notes.
  • Skill values are cross-checked. Keen does not publish every rank, percentage and point cost. For those we use community planners built from the 1.0 game files and only state a number when a second 1.0 source agrees. If sources disagree, the guide says so.
  • Competitor and community guides are compared before a build is changed, so our tiers and skill orders reflect where the community agrees and explain where we differ.
  • Every page shows the review date and the game version it was checked against (currently 1.0.0.2 (Steam build 1269579)), and lists its sources at the bottom.
  • Corrections are welcome. If a tooltip in your game shows a different value, tell us and we will re-check it.

The skill planner

Our Enshrouded skill planner draws the real 1.0 skill tree, with the node positions and links exported from the game files by the open-source rossicler/enshrouded-skill-tree project (GPL-3.0). We checked that export against our own skill table: all 178 skills match on ranks and point costs. The planner code and its data are released under the GPL-3.0 as well.
