    Enshrouded skill tree planner for the 1.0 release

    Enshrouded 1.0 reset every character's skill tree, so most players are re-planning their build right now. This Enshrouded skill tree planner lets you do that before you spend a single point in the game. It draws the full 1.0 tree, with 231 nodes covering 178 different skills, at the positions and with the links the game uses. Like in Enshrouded itself, you can only learn a skill that connects to one you already have.

    Use the skill planner to test a new build, compare two paths to the same capstone, or check how many points a hybrid really costs. When you like the result, copy the build link and share it with your group.

    How to use the Enshrouded skill planner

    1. Load a build or start empty. Each preset is the level 50 version of one of our guides, following real paths through the tree: Wizard · Battlemage · Necromancer · Healer · Warrior · Tank · Barbarian · Ranger · Assassin.
    2. Start at the center. Glowing nodes are the ones you can learn now, starting from the entry nodes next to the center ring.
    3. Click to add a rank, right-click to refund. On phones, tap once to see a skill and tap again to add it; use the − button in the details panel to refund. Refunding a skill also refunds anything that would lose its connection.
    4. Set your level, Flame level and explored biomes. The planner adjusts your point budget and attributes to match.
    5. Share it. The address updates with every click, so Copy build link always shares your current plan.

    Enshrouded build calculator: skill points at every level

    The planner works as a skill point calculator too. You earn 2 skill points per level after level 1 (98 at level 50), 1 point for every Shroud Root and 3 for every Elixir Well. Exploration adds 114 points across the seven biomes, for 212 skill points at level 50 on a fully explored character. Filling the whole tree would cost 675 points, so every Enshrouded build has to commit to one area and borrow only the best skills from its neighbours. Untick the biomes you have not finished yet to see your real budget today.

    Respec your build after the 1.0 reset

    Every existing character got a free skill tree reset when loading a save in 1.0. After that, you respec at the Flame Altar. Plan the new build in the skill planner first so you only respec once. The skill tree guide explains respec costs and rules, and lists every skill with its effect.

    Skill planner FAQ

    How many skill points do you get in Enshrouded 1.0?

    212 at level 50 if you explore everything: 2 points for every level from 2 to 50 (98), plus 114 from exploration, 1 for each Shroud Root and 3 for each Elixir Well, spread over the seven biomes.

    How many points does it take to fill the whole skill tree?

    675 points. A level 50 character can afford roughly a third of the tree, so every build has to choose.

    Is there an Enshrouded skill calculator or build planner?

    Yes, this page. The Enshrouded skill planner works as a skill calculator and build planner in one: it adds up the points your build costs, compares them with your budget for your level and explored biomes, and shows the attributes you end up with.

    Does this planner follow the real skill tree connections?

    Yes. The tree uses the node positions and links exported from the Enshrouded 1.0 game files: 231 nodes and 291 links. You can only learn a skill that connects to one you already have, starting from the entry nodes around the center, exactly like in the game. Refunding a skill also refunds anything that would lose its connection.

    Is this the same skill tree as the game?

    Yes. The data comes from the 1.0 game files (Steam build 1267041), including the in-game skill text you see in the details panel. Keen Games can still change values in hotfixes, so the in-game tooltip always wins.

    Can I share my build?

    Yes. Every change updates the page address. Use Copy build link and send it to a friend: the link opens the planner with your exact build, level, flame level and explored biomes.

    What does the Flame level do?

    Every Flame level after the first adds 1 point to each attribute, and Flame nodes like Thick Skin or Exalted add 1 more point of their attribute for every 2 Flame levels.
