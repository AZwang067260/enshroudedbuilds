    How to use the Enshrouded skill planner

    1. Set your progress. Enter your level and how many Shroud Roots and Elixir Wells you have cleared. The planner works out your point budget: 2 per level after level 1, 1 per Shroud Root and 3 per Elixir Well.
    2. Load a build or start empty. Each preset is the level 50 version of one of our guides: Wizard · Battlemage · Necromancer · Healer · Warrior · Tank · Barbarian · Ranger · Assassin.
    3. Add and remove ranks with the + and − buttons. Point costs differ a lot: attribute nodes cost 1 point, big skills like Blink or Swift Blades cost 4, and Flame nodes cost 5.
    4. Watch your attributes. Attribute nodes, the Ranger node and the Flame nodes (Thick Skin, Barbarian, Exalted, Arcane Concentration, Graceful Stride, Endurance of the Flame) add to your stats. Flame nodes give +1 for every 2 Flame levels.
    5. Share it. The link updates with every click, so Copy link always shares your current plan.

    Enshrouded 1.0 skill points explained

    The 1.0 skill tree has 231 nodes and 178 skills across the Core and the three class areas: Mage (Wizard, Healer, Battlemage, Trickster), Warrior (Tank, Warrior, Barbarian, Athlete) and Ranger (Ranger, Assassin, Beastmaster, Survivor). Filling every node would cost 675 points, but a fully explored level 50 character has 212. That is why every build has to commit to one area and borrow only the best skills from its neighbours. Read the skill tree guide for how the areas fit together.

    Skill planner FAQ

    How many skill points do you get in Enshrouded 1.0?

    212 at level 50 if you explore everything: 2 points for every level from 2 to 50 (98), 1 point for each of the 60 Shroud Roots and 3 points for each of the 18 Elixir Wells (114 together).

    How many points does it take to fill the whole skill tree?

    About 675 points, according to community planners built from the 1.0 game files. A level 50 character can afford roughly a third of the tree, so every build has to choose.

    Does this planner check skill tree connections?

    Not yet. It checks your point budget, ranks and attributes. In the game you can only take a skill that connects to one you already own, so plan your path through the tree as well. Our build guides list the order that works.

    Is this the same skill tree as the game?

    It lists all 178 skills and 231 nodes of the 1.0 tree with their ranks and point costs, taken from community data exported from the game files (Steam build 1267041) and checked against other 1.0 sources. Values marked as disputed differ between sources, so check the in-game tooltip.

    Can I share my build?

    Yes. Every change updates the page address. Use the Copy link button and send it to a friend: the link opens the planner with your exact build, level and exploration settings.
