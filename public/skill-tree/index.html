Enshrouded 1.0 Skill Tree Guide

How the Enshrouded skill tree works in 1.0: all twelve archetypes, the six attributes, skill points and resets, and how to plan a build that reaches level 50.

How the Enshrouded skill tree works

The Enshrouded skill tree is one large connected web that every character shares. You start in the middle and unlock nodes outward with skill points earned from leveling. Some nodes are small attribute increases, others are passive bonuses, and a few are build-defining skills like Blink, Unity or Battle Heal. Nodes are grouped into archetypes, and your build is the shape your path makes through them.

The 1.0 skill tree layout

In Update 1.0 the tree is organized as three main trees, Warrior, Ranger and Mage, branching out from a shared Core of general skills in the center. Community planners built from the 1.0 game files count 231 nodes (243 if you include the 12 free "Spark" starting nodes) and 178 distinct skills. The Core alone holds 19 skills that any build can take, such as Merciless Attack. Inside each main tree, the familiar archetype groups remain: Wizard, Battlemage, Healer and Trickster sit in the Mage tree, for example. That is why build guides, including ours, still name builds after archetypes.

A fully explored level 50 character has 212 skill points: 98 from levels, 60 from Shroud Roots and 54 from Elixir Wells. Filling the whole tree would cost roughly 675 points, so you can afford about a third of it: enough to max one main tree and reach into a second. Try it in the skill planner.

Planning a build in 1.0

Update 1.0 (October 15, 2026) reset every skill tree, so everyone is re-spending points right now. The Enshrouded 1.0 builds guide has the full re-spec checklist. With the level cap at 50, you have more points than in Early Access, but still not enough to fill everything. The best builds pick one main archetype, go deep for its key skills, and use a neighbouring archetype for support: Tank armor for a Warrior, Battlemage sustain for a Wizard, Assassin crits for a Ranger. Avoid spreading single points across the whole tree. Many weak nodes add up to much less than a few strong capstones.

Utility archetypes like Athlete, Trickster, Beastmaster and Survivor are rarely a build's main focus, but one or two of their nodes can help a lot with movement, control or exploring the Shroud.

Enshrouded skill points: how many you get

You earn 2 skill points per level after level 1, so 98 by the level 50 cap. Exploration adds the rest: 1 point for each Shroud Root you destroy and 3 points for each Elixir Well you cleanse, 114 points across the seven biomes. A fully explored level 50 character has 212 skill points, while the whole tree (231 nodes, 178 different skills) costs 675. The Enshrouded skill planner calculates your budget for any level and set of explored biomes.

How to respec in Enshrouded 1.0

Every existing character got one free skill tree reset when loading a save in Update 1.0, with all points refunded. After that:

  • Full respec: use the Flame Altar. Since a 2024 update the cost has been 1 Rune per skill point you had spent; this has not been re-confirmed for 1.0 yet, so check the altar before you commit.
  • Single nodes: you can unlearn a skill in the tree only if nothing you still own depends on it, so refund from the end of a chain.
  • Plan first: build the new layout in the skill planner so you only pay for one respec.

Skill tree FAQ

How many archetypes are in the Enshrouded skill tree?

Twelve, in three combat areas: Warrior (Warrior, Tank, Barbarian, Athlete), Mage (Wizard, Battlemage, Healer, Trickster) and Ranger (Ranger, Assassin, Beastmaster, Survivor).

How do you get skill points in Enshrouded?

Three ways: 2 points per level up to the 1.0 cap of 50, 1 point for each Shroud Root you destroy, and 3 points for each Elixir Well you cleanse.

Can you reset skills in Enshrouded?

Yes. Respec at a Flame Altar; the cost has been 1 Rune per skill point you spent since a 2024 update (not yet re-confirmed for 1.0). In the tree you can also unlearn single nodes from the end of a chain. Everyone also got one free reset when loading a save in 1.0.

How many skill points do you get at level 50?

212 in total if you explore everything: 98 from levels 2–50, 60 from Shroud Roots and 54 from 18 Elixir Wells, according to community planners built from the 1.0 game files.
