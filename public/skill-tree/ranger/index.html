Enshrouded Ranger Skill Tree (1.0)

The Ranger area covers bows, daggers and survival: bow damage and weak points in the Ranger group, crits, daggers and gliding in Assassin, hunting utility in Beastmaster and exploration perks in Survivor. In 1.0 it gained three new archer skills and all of the dagger skills.

Open the Ranger area in the plannerWhole skill tree

The Ranger area at a glance

The Ranger area has 73 nodes and 60 different skills. Maxing every one of them would cost 215 points, which is 101% of the 212 points a fully explored level 50 character has. So no build can take the whole area: you choose a path through it.

What's new in the Ranger skill tree in 1.0

Where to start in the Ranger area

A few nodes can be learned without owning a neighbour. They are the entry points of the Ranger area:

  • Dexterity node (1 pt) leads to Airborne
  • Dexterity node (1 pt) leads to Marksman
  • Endurance node (1 pt) leads to Mithridatist
  • Endurance node (1 pt) leads to Runner

From there, a node unlocks once it connects to one you already have. Use the planner to see the cheapest path to any skill.

Ranger leveling route: level 1 to 50

Every build in this area follows the same three stages. Points come from levels and from the Shroud Roots and Elixir Wells you clear, so each stage below assumes you have explored the biomes that match your level. Each link opens that stage's preset in the planner:

BuildStage 1Stage 2Stage 3
RangerLevels 1–15 (65 pt)Levels 16–35 (140 pt)Levels 36–50 (212 pt)
AssassinLevels 1–15 (65 pt)Levels 16–35 (140 pt)Levels 36–50 (212 pt)

The general rule: in stage 1 take your weapon's specialization and the first damage nodes of your main group, in stage 2 buy and max the build-defining skills, and in stage 3 finish capstones and reach into one neighbouring group for defense or sustain. Each class guide explains why its skills come in that order.

Ranger skill tree FAQ

How many skills are in the Enshrouded Ranger skill tree?

The Ranger area of the 1.0 tree has 73 nodes and 60 different skills in 4 groups (Ranger, Assassin, Beastmaster, Survivor). Maxing every node would cost 215 skill points, against a budget of 212 at level 50.

What is new in the Ranger skill tree in 1.0?

1.0 added Puncture, Barrage, Survival Instinct. The Ranger area also received every dagger skill from the Warrior area, so dagger builds now live entirely here. The 1.0 skill tree changes post lists the moved skills.

Where do you start in the Ranger area?

From its starting nodes, which you can learn without owning a neighbour: Dexterity node (1 pt); Dexterity node (1 pt); Endurance node (1 pt); Endurance node (1 pt).

Which builds use the Ranger skill tree?

Our Ranger, Assassin builds spend most of their points in the Ranger area.
