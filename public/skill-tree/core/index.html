Enshrouded Core Skill Tree (1.0)

The Core sits in the middle of the tree and holds the general skills any build can take: Merciless Attack and its upgrades, Double Jump, grappling hooks, Shroud time, and tool and gathering skills. Most of them are cheap, and several are starting nodes you can learn without a neighbour.

Open the Core area in the plannerWhole skill tree

The Core area at a glance

The Core area has 20 nodes and 20 different skills. Maxing every one of them would cost 53 points, which is 25% of the 212 points a fully explored level 50 character has. You could fill it, but most builds only take the few skills they need.

What's new in the Core skill tree in 1.0

1.0 added these skills to the Core area. Values are the in-game text at max rank:

Inner Fires and Snap were repositioned in 1.0, and Shroud time bonuses such as Inner Fires stack less well than before, according to the 1.0 changelog.

Where to start in the Core area

A few nodes can be learned without owning a neighbour. They are the entry points of the Core area:

  • Double Jump (2 pt) leads to Airborne Architect
  • Fisherman's Resolve (1 pt × 3) leads to nothing else: it is a single node
  • Giant Slayer Hook (3 pt) leads to Grounding Hook
  • Lumberjack (1 pt × 3) leads to Felling Axe Specialization, Quality Gear
  • Mason (1 pt × 3) leads to Pickaxe Specialization, Prospector
  • Merciless Attack (2 pt) leads to Power Parry, Snap
  • Power Parry (1 pt × 3) leads to Merciless Attack, Opportunity
  • Saviour (1 pt × 3) leads to nothing else: it is a single node
  • Well Rested (1 pt × 3) leads to Inner Fires

From there, a node unlocks once it connects to one you already have. Use the planner to see the cheapest path to any skill.

Core leveling route: level 1 to 50

Core skills are cheap, so most builds pick up a few of them on the way to their own area. These are the Core skills our nine 1.0 presets take:

  • Double Jump: Wizard, Battlemage, Necromancer, Healer, Warrior, Tank, Barbarian, Ranger, Assassin
  • Power Parry: Battlemage, Warrior, Tank
  • Merciless Attack: Warrior, Tank, Barbarian
  • Saviour: Healer
  • Sneak Attack: Assassin

Core skill tree FAQ

How many skills are in the Enshrouded Core skill tree?

The Core area of the 1.0 tree has 20 nodes and 20 different skills. Maxing every node would cost 53 skill points, against a budget of 212 at level 50.

What is new in the Core skill tree in 1.0?

1.0 added Airborne Architect. Inner Fires and Snap were repositioned in 1.0, and Shroud time bonuses such as Inner Fires stack less well than before, according to the 1.0 changelog.

Where do you start in the Core area?

From its starting nodes, which you can learn without owning a neighbour: Double Jump (2 pt); Fisherman's Resolve (1 pt × 3); Giant Slayer Hook (3 pt); Lumberjack (1 pt × 3); Mason (1 pt × 3); Merciless Attack (2 pt); Power Parry (1 pt × 3); Saviour (1 pt × 3); Well Rested (1 pt × 3).
